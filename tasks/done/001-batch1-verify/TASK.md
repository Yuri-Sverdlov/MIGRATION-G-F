# TASK-01: проверка партии 1 и подготовка к удалению оригиналов

> Задание: архитектор -> кодер. Отчёт пиши в `tasks/REPORT.md`.
> Правила среды: `AGENTS.md` (читай первым).

## Контекст

6 папок из `G:\AI\` скопированы на `F:\` и проверены по числу файлов.
Пути приложений (Ollama, LM Studio) переключены на F:.
**Оригиналы на G: ещё не удалены.**

Твоя задача — убедиться, что приложения реально работают с новыми путями,
и подготовить финальный отчёт для архитектора. Удаление оригиналов делает
пользователь вручную (хук блокирует агенту деструктивные команды — это норма).

## Шаги

### 1. Проверка Ollama (F:\OLLAMA-LMSTUDIO\OllamaModels)

Выполни и вставь **полный вывод** каждой команды в REPORT.md:

```
ollama list
```

Ожидание: список моделей (хотя бы 1 строка с именем модели и размером).
Если список пуст — проверь переменную:

```
[System.Environment]::GetEnvironmentVariable('OLLAMA_MODELS','User')
```

Должно быть `F:\OLLAMA-LMSTUDIO\OllamaModels`.

Если модели видны — запусти **короткий** тест любой доступной модели:

```
echo "Say only: OK" | ollama run <имя_модели_из_списка>
```

Вставь вывод в отчёт. Если модель ответила — Ollama работает с F:.

### 2. Проверка LM Studio (F:\OLLAMA-LMSTUDIO\GGUF_Models)

LM Studio — GUI-приложение. Кодер не может его открыть.
Вместо этого проверь, что файлы моделей на месте:

```
$models = Get-ChildItem -Path "F:\OLLAMA-LMSTUDIO\GGUF_Models" -Recurse -File
$models.Count
$models | Select-Object FullName, Length | Out-String
```

Вставь вывод (количество и список файлов) в отчёт.
Визуальную проверку «модели видны в My Models» сделает пользователь.

### 3. Контрольное сравнение: оригиналы ещё на месте

Убедись, что оригиналы на G: ещё существуют (до удаления пользователем):

```
$folders = @(
  "G:\AI\MonteCarloOptimizationKimi",
  "G:\AI\OBSIDIAN-KNOWLEDGE-BASE",
  "G:\AI\TOMATO-2-TIMERS",
  "G:\AI\COURSES",
  "G:\AI\OLLAMA-LMSTUDIO",
  "G:\AI\OllamaModels"
)
foreach ($f in $folders) {
  $exists = Test-Path $f
  $count = if ($exists) { (Get-ChildItem $f -Recurse -File).Count } else { 0 }
  "$f -> exists=$exists, files=$count"
}
```

Вставь вывод в отчёт. Это нужно для протокола: подтвердить, что на момент
проверки оригиналы целы.

### 4. Заполни REPORT.md

В отчёте должно быть:

- Вывод `ollama list` (полный текст, не пересказ).
- Вывод тестового запуска модели.
- Количество и список файлов LM Studio на F:.
- Таблица существования оригиналов на G: (шаг 3).
- Итоговый вердикт: «Партия 1 проверена, приложения работают с F:,
  оригиналы готовы к удалению пользователем» — либо описание проблем.
