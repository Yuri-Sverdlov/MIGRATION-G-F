## 1. Метод (работает, не менять)

1. **Копия:** `robocopy SRC DST /E /COPY:DAT /R:1 /W:1` (гиганты: `/MT:16`, в фоне).
2. **Проверка:** `(Get-ChildItem SRC -Recurse -File).Count` = dst. **Без match — не успех.**
3. **Пути:** массовая замена в операционных файлах на F: + внешние настройки приложений.
4. **Удаление G:** только после приёмки архитектором. Агент **не удаляет** (хуки блокируют).

**Целевой корень:** `F:\`, **не** `F:\AI\`. Ошибка TASK-02: кодер положил RUNPOD в `F:\AI\...` — исправлено архитектором.

## 2. Грабли и решения

### 2.1. Форматы путей (критично)

Жёсткие ссылки встречаются в **четырёх** формах — скан должен покрывать **все**:

| Формат | Пример |
|--------|--------|
| Windows | `G:\AI\_MY_PROGRAMMING\` |
| Forward slash | `G:/AI/_MY_PROGRAMMING/` |
| Escaped (Python/JSON) | `G:\\AI\\_MY_PROGRAMMING\\` |
| Lowercase | `g:\AI\...`, `g:/AI/...` |

**Урок TASK-04:** кодер заявил `hits=0`, но пропустил `G:/AI/` и `G:\\AI\\` — архитектор доделал 7 `.py`.

**JSON-кэши** (`_reports\inventory.json`, `logs/*.json`): пути как `G:\\AI\\...` — SimpleMatch по `G:\AI\` **не находит**. Логи — история; **config.json** с `G:\\AI\\` — операционный, править обязательно (TASK-07: `ref_audio`).

**JSON-escaped в .json:** замена `G:\\AI\\` -> `F:\\` отдельно от `G:\AI\` (TASK-07).

### 2.2. Обратные ссылки (вне scope папки)

Миграция папки A не чинит ссылки **из уже мигрированной** папки B.

**Примеры:**
- TASK-05: `F:\_MY_PROGRAMMING_2\ComfyUI\extra_model_paths.yaml` всё ещё указывал на `G:/AI/COMFYUI-SHARED` — в scope TASK не входил, но критичен для запуска.
- TASK-04: обратные ссылки в `_MY_PROGRAMMING_4`, `_MY_PROGRAMMING_IVRIT` — отдельный прогон скрипта.

**Правило:** после каждой партии grep по **всем уже мигрированным** папкам на F: по имени перенесённого каталога.

### 2.3. Кириллица в путях

- Не передавать кириллический путь **строкой** в команде агента.
- Искать по ASCII-имени файла (`extra_models_config.yaml`), работать через `FileInfo.FullName`.
- **COMFY_UI:** legacy `G:\С 2ТБ\COMFY_UI` -> regex `G:\\[^\\]+\\COMFY_UI` -> `F:\COMFY_UI`.

### 2.4. Ложные совпадения при скане

- Строки кода `"...string:\n"` дают `g:\` (Select-String case-insensitive).
- `TYPE_CHECKING` в Python содержит подстроки, похожие на пути — не трогать.
- **Не менять:** git-remote URL, VPS Linux-пути, пути на других дисках (`G:\Video`, `S:\`), `session-*.json`.

### 2.5. Что не переносится / не правится

| Объект | Действие |
|--------|----------|
| `.venv` | Пересоздавать при необходимости, не править пути внутри |
| `site-packages`, `python_embeded\Lib` | Не сканировать/не менять |
| Настройки приложений | Ollama `OLLAMA_MODELS`, LM Studio — **снаружи** папки, чинить отдельно |
| `_planning\`, `.md`-история | Можно оставить старые пути (документация) |

### 2.6. Сабагенты Hermes — не для массовой замены

**TASK-03:** сабагент упал (`Billing credits exhausted`), кодер отчитался «готово» до проверки. Архитектор доделал 136 файлов вручную.

**Правило:** массовую замену — PowerShell-скрипт **в основной сессии**, без сабагентов.

### 2.7. Блокировка файлов при удалении

Папки на G: часто **не удаляются** пока работает Hermes/кодер/python/node/Ollama.
**TASK-06 (2026-09-10):** после закрытия Проводников папки остались заблокированы —
виновник **GoogleDriveFS.exe** (Google Drive File Stream) держал handle на пустые папки.
Диагностика: `handle64.exe` (Sysinternals, `https://live.sysinternals.com/handle64.exe`)
показывает процесс-владелец handle. Лечение: `Stop-Process -Id <pid> -Force` +
`cmd /c rd /s /q "\\?\путь"`.

**Решение:**
1. Закрыть терминал кодера / Hermes.
2. Shift+Delete в Проводнике.
3. Если не помогает — **reboot**, затем удаление **до** запуска агента.
4. Проверить `handle64.exe`: возможно, handle держит GoogleDriveFS (синк `G:\AI\`).

Список: `DELETE-AFTER-REBOOT.md` (на 2026-08-25 — **10 папок**).

### 2.8. Хуки безопасности (DEV-NOTES §15)

- `Remove-Item -Recurse`, `del`, `format` — **блокируются**. Это норма.
- `Format-Table` / `Format-List` — **ложный триггер** на `format` (диск). Использовать `Out-String`, `foreach { "..." }`.
- Удаление 188 ГБ — только пользователь, Shift+Delete.

### 2.9. Robocopy

- Exit code **0–7** = успех (1 = скопированы новые файлы — норма).
- Гиганты (>50k файлов): `/MT:16`, фон, ждать завершения перед проверкой.
- COMFYUI-SHARED: 221 файл, ~550 GB (модели) — robocopy долгий по объёму, не по счётчику.

### 2.10. Порядок партий ComfyUI

SHARED (221) **до** PORTABLE (57472): PORTABLE ссылается на SHARED в `extra_model_paths.yaml`.

### 2.11. Внешние настройки (партия 1)

После копии Ollama/LM Studio папок **недостаточно** — нужно:
- `OLLAMA_MODELS` (user + machine env)
- LM Studio `downloadsFolder`
- Проверка: `ollama list`, тестовый prompt, наличие GGUF на F:

### 2.12. Приёмка архитектором

Кодер **не финал**. Архитектор:
1. Независимо пересчитывает файлы.
2. Читает ключевые конфиги вручную.
3. Прогоняет контрольный скан **шире**, чем в TASK.
4. Доделывает пропуски (прецедент: TASK-02, 03, 04, 05).
5. Пишет `ACCEPTED.md`, архивирует в `tasks/done/NNN-*/`.

### 2.13. Отчёт кодера

Типичные пробелы:
- Таблицы с `...` вместо полных данных.
- «GUI не проверял» — OK, если не в scope, но зафиксировать.
- «Завершено» без контрольного скана — **не принимать** без перепроверки.
