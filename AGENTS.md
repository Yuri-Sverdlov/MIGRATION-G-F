# AGENTS.md — устав кодера (MIGRATION-G-F)

Читай `tasks/TASK.md` — там одно активное задание, самодостаточное. Результат пиши в `tasks/REPORT.md`.

## Правила среды
- Оболочка — PowerShell 7 (`pwsh`). Вывод в консоль — только ASCII (`->`, `<=`). Файлы — UTF-8. (DEV-NOTES §4, §5, §12)
- Кириллические пути не передавать строкой — искать по ASCII-признаку, работать объектом `FileInfo.FullName`. (DEV-NOTES §5)

## Метод миграции
- Копия — только `robocopy SRC DST /E /COPY:DAT /R:1 /W:1` (гиганты — добавить `/MT:16`, запускать в фоне).
- Проверка обязательна: число файлов src = dst (`Get-ChildItem -Recurse -File`). Без совпадения — не считать перенос успешным.
- Оригинал на G: удалять ТОЛЬКО после проверки копии.

## Безопасность (важно)
- Действуют хуки: блокируются `rm -rf`, `Remove-Item -Recurse/-Force`, `del`, `format`, `diskpart`. Это норма, не баг. (DEV-NOTES §15)
- Удаление больших оригиналов — не через агента (хук блокирует). Через Проводник (Shift+Delete, 188 ГБ мимо Корзины) или силами пользователя.
- Файлы `nul`/`con`/`aux`/`prn` удаляются только: `cmd /c del "\\?\полный_путь"`.
- ⚠️ Не использовать `Format-Table`/`Format-List` в командах — хук ложно принимает «Format» за `format` (диск) и блокирует. Использовать `Out-String` или ручной вывод (`foreach { "..." }`).

## Замена путей (обязательно)
- Сканировать **все форматы:** `G:\AI\`, `G:/AI/`, `G:\\AI\\`, `g:\AI\`, `g:/AI/`.
- **Не использовать сабагентов** для массовой замены (credits + нет гарантии результата).
- После замены в своей папке — проверить **обратные ссылки** в уже мигрированных папках на F:.
- Кириллические пути — через `FileInfo.FullName`, не строкой в команде.
- Не трогать: `site-packages`, `.venv`, `_planning\` (история), пути других дисков.

## Что не делать
- Не удалять оригинал до проверки. Не трогать чужие папки вне задания. Не запускать деструктив в обход хуков.
- Не класть копии в `F:\AI\` — целевой корень **`F:\`**.
